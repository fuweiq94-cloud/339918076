本仓库是一个 .NET Framework 4.6.1 类库工程（ProcessModules.csproj），通过 Solution 文件聚合 PointJump、MainControl、Trajectory 三个子项目，并将它们的所有 .cs 源文件直接 Compile Include 到同一个 DLL 中，实现「零引用」的双向隔离：不引用外部 XyzController/InterfaceDefine/MainModule，而是把业务层（Logic）、自定义控件（Controls）以及各模组的 RunForm 全部移植到本项目内，仅依赖外部 InterfaceDefine.dll 和 MainModule.dll 提供的 ProcessModuleBase、AppParam、ProjectManager 等接口。三个工艺模组共享同一套 XyzControllerHub/AxisController 运动控制抽象与 XYView/ZBarView/DroLabel/JogButton 控件集，通过统一的 XML 序列化结构（GlobalSetting/ProjectSetting/PresetPoint）完成参数持久化。
