模块以 `TrajectoryViewProcessModule`（继承平台基类 `ProcessModuleBase`）为入口，遵循 DOMO 模式：模块持有业务层 `XyzControllerHub`，运行界面 `RunForm` 通过构造函数注入模块引用，形成「模块 → Hub → UI」单向依赖。
- 配置层：`TrajectoryGlobalSetting`（全局参数，存于 AppParam/ProcessModule/<模组名>/TrajectoryGlobalSetting.xml）与 `TrajectoryProjectSetting`（项目参数，随项目路径切换）均通过 XML 序列化持久化。
- 业务层：`XyzControllerHub`（来自上层 Logic 目录，通过 `<Link>` 引用编译）封装 XYZ 轴控制、轨迹点记录与速度管理。
- UI 层：`RunForm` 组合 `XYView`（XY 平面轨迹绘制）、`ZBarView`（Z 轴条形图）、`DroLabel`（数字读数）等自定义控件，所有事件订阅在 `OnLoad` 中完成以避免设计器触发副作用。
- 命令路由：`Action()` 通过 switch 分发 GOTO/ORIGIN/CENTER/RANDOM/CLEARTRAIL/SHOWTRAIL/SETSPEED/STOP 等命令，统一经 `_hub` 执行。
- 构建方式：`.csproj` 使用 `<Compile Include="..\Logic\*.cs" Link="...">` 和 `<Compile Include="..\Controls\*.cs" Link="...">` 将共享逻辑与控件以链接文件形式纳入本 DLL，输出 `Trajectory.dll`。
