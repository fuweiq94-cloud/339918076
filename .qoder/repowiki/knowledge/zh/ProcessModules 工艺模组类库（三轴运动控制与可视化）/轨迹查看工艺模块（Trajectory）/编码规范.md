- 配置类统一提供静态 `Load(name)` 与实例 `Save()` 方法，通过 `InterfaceDefine.CommKit.XMLSerializationHelper` 进行 XML 序列化，失败时返回空对象并记录调试日志。
- 命令处理集中在 `Action(params object[] param)` 中，通过 `param[0].ToString().ToUpper()` 做大小写无关的命令分发，参数不足时调用 `InsertAlarm` 上报错误码。
- UI 初始化全部放在 `OnLoad` 而非构造函数中，避免 VS 设计器仅执行构造函数导致的红屏异常，事件订阅采用显式 `new EventHandler(...)` 兼容旧编译器。
- 跨线程回调（如 `Hub_Changed`）统一通过 `InvokeRequired` + `BeginInvoke` 切回 UI 线程后再刷新控件，保证线程安全。
- 模块与 UI 通过属性双向同步状态（如 `ShowTrail`、`ApplyRanges()`），保存后由 `Save()` 调用 `ApplyRanges()` 自动将新范围应用到 Hub 和视图。
