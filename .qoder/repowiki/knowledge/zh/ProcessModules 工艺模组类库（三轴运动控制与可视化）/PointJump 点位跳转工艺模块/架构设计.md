模块基于 .NET Framework 4.6.1 的 Windows Forms 库项目（PointJump.csproj），输出 PointJump.dll，命名空间为 PointJumpProcessModule。整体采用三层结构：
- 平台适配层：`PointJumpProcessModule` 继承 `ProcessModuleBase`（来自 MainModule），实现 Init/Action/Save/LoadSetting/ShowRunForm 等平台接口，是模块唯一对外入口。
- 业务逻辑层：通过链接方式引用父目录 `Logic\` 下的共享类（AxisController、AxisPosition、XyzControllerHub、MotionCommand、IMotionService），由 Hub 统一封装 XYZ 轴运动控制。
- UI 层：`RunForm` 作为纯界面层，仅负责用户输入捕获与状态刷新，所有运动逻辑委托给 `_hub`；设置界面通过 `ModuleSettingForm` 复用。
- 配置持久化：`PointJumpGlobalSetting`（全局参数，AppParam/ProcessModule/模组名）与 `PointJumpProjectSetting`（项目参数，当前项目路径/模组名）均通过 XML 序列化存储。
依赖方向单向：UI → 模块 → Hub → 硬件；模块与 UI 通过共享 `PresetPoint` 列表实例保持数据一致。
