- 所有事件订阅使用显式 `new EventHandler(...)` 命名方法形式而非 Lambda，以兼容工控机上旧 .NET 编译器。
- UI 层的业务初始化全部放在 `OnLoad` 中而非构造函数，避免 VS 设计器触发副作用导致红屏异常。
- 跨线程回调（如 Hub.Changed）通过 `InvokeRequired` + `BeginInvoke` 切换回 UI 线程再更新控件。
- 配置加载/保存统一通过 `InterfaceDefine.CommKit.XMLSerializationHelper` 静态方法完成，失败时返回默认对象并记录 Debug 日志。
- 命令解析在 `Action(params object[] param)` 中使用 `switch(swName.ToUpper())` 分发，参数校验失败时调用 `InsertAlarm` 并返回负错误码。
- 模块变量通过 `SetModuleVariable` / `GetModuleVariable` / `GetStringVariable` 访问，标准变量在 `LoadSetting` 中统一注册初始值。
