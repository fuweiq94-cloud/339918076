- 配置类均提供静态 `Load(name)` 与实例 `Save()` 方法，通过 `InterfaceDefine.CommKit.XMLSerializationHelper` 读写 XML 文件，失败时返回默认实例并记录调试日志。
- 平台命令通过 `Action(params object[])` 中的 `switch(swName.ToUpper())` 分发，参数校验失败时调用 `InsertAlarm` 并返回负错误码（-1 未知命令、-2 参数错误、-3 超限）。
- JOG 模式切换统一通过 `ApplyJogSetting()` 遍历 `_jogServices` 数组调用 `SetMode` 与 `SetStepDistance`，保持全局设置与所有轴服务同步。
- UI 与业务状态同步采用事件驱动：订阅 `_hub.Changed` 并在 `InvokeRequired` 时 `BeginInvoke` 切回 UI 线程刷新，避免跨线程访问控件。
- 窗体构造区分无参（VS 设计器）与带参（运行时注入 `MainControlProcessModule`）两种构造函数，运行时实例通过 `TopLevel = false` + `Dock = Fill` 嵌入 Panel。
