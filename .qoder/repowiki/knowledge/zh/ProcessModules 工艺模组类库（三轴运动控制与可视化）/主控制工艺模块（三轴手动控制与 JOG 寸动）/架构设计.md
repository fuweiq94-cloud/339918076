模块以 `MainControlProcessModule`（继承 `ProcessModuleBase`）为入口，遵循平台工艺模组标准生命周期（Init/LoadSetting/Save/Action/ShowRunForm/ShowSettingForm）。内部采用三层结构：
- 配置层：`MainControlGlobalSetting`（全局 XML 配置，路径 `AppParam\ProcessModule\模组名\MainControlGlobalSetting.xml`）与 `MainControlProjectSetting`（项目级 XML 配置，随项目切换）。
- 业务层：通过链接文件引用共享的 `Logic\XyzControllerHub`、`AxisJogService`、`JogMode`、`MotionCommand` 等，每个轴一个 `AxisJogService`，由 Hub 统一管理轴范围与速度。
- UI 层：`UnifiedRunForm`（统一界面，含 XYView/ZBarView/DRO/JOG 按钮/预设点位）、`RunForm`（基础界面）、`AxisLimitForm`（轴限位设置），均由 `MainControlProcessModule` 托管显示。
依赖方向单向：UI → Module → Hub → AxisJogService，配置文件通过 `InterfaceDefine.CommKit.XMLSerializationHelper` 序列化。
