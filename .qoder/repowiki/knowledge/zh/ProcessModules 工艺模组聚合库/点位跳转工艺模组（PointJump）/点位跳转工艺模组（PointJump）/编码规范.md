- 全局参数与项目参数分别通过静态 Load(name) 和实例 Save() 方法完成 XML 序列化，路径统一拼接 AppParamPath 或 ProjectManager.projectSetting.strProjectPath。
- 参数类使用公共字段而非属性，注释明确说明是为了兼容 XML 序列化。
- Action 命令解析采用 switch(string.ToUpper()) 分支，每个分支先校验参数长度再执行，失败时调用 InsertAlarm 记录错误并返回负值。
- 界面与工艺层共享对象（_hub、projectSetting.Presets、runForm）并通过刷新方法（RefreshPresets、ApplyRanges）保持 UI 同步，而非事件通知。
- 异常处理统一在 try/catch 中捕获后 MessageBox.Show 提示，并回退到默认配置以保证模块可用性。
