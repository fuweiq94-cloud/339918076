模块以 PointJumpProcessModule 为核心入口，继承平台 ProcessModuleBase，在 Init 中创建 XyzControllerHub 业务层并加载 PointJumpGlobalSetting（AppParam\ProcessModule\模组名）与 PointJumpProjectSetting（当前项目路径\模组名）两类 XML 配置；RunForm 作为 UI 层通过构造函数注入模组实例，与 Hub、projectSetting.Presets 共享同一数据源，采用事件驱动（_hub.Changed）实现硬件状态到 UI 的单向同步。Action 方法统一解析平台命令（GOTO/GOTOPOINT/SAVEPOINT/DELETEPOINT/SETSPEED/STOP），SetParam/GetParam 暴露 SpeedSetting、PresetCount、JumpCount、CurrentX/Y/Z 等变量供主平台调用。保存时通过 ApplyRanges 将全局轴范围同时应用到 Hub 和 RunForm，保证设置界面修改后运行界面即时生效。
