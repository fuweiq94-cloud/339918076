本模块采用「接口 + 命令 + 适配器」的分层设计：
- 抽象层：`IMotionService` 定义统一的后端服务契约（ExecuteCommand / PositionUpdated / Open/Close），所有硬件交互必须通过该接口。
- 命令层：`MotionCommand` + `MotionCommandType` 将移动、回原点、急停、设速等全部操作收敛到单一 ExecuteCommand 入口，按 CommandType 分发。
- 数据层：`AxisPosition` 封装多轴 Target/Actual/IsMoving/IsHomed/IsAlarmed 快照及时间戳，通过 `AxisPositionEventArgs` 事件推送。
- 业务层：`XyzControllerHub` 持有四个 `AxisController`（X/Y/Z/U），负责把用户操作转换为 MotionCommand 并转发给 IMotionService；同时订阅 PositionUpdated 事件将后端实际位置写回各轴的 Current。
- 轴控制层：`AxisController` 管理单轴的 Min/Max/Current/Target，提供 SetTarget、Step、Advance（插值动画）、UpdateCurrent 等方法，不依赖任何 UI。
- JOG 服务：`AxisJogService` 将按钮按下/松开映射为对 AxisController 的目标设置，支持 Incremental（寸动）和 Continuous（连续）两种模式。
- 平台适配层：`PlatformMotionAdapter` 实现 IMotionService，内部以 object 引用平台 DLL 对象，通过 switch(command.CommandType) 调用 moveABS/movego/movehoome 等平台方法；`PlatformMotionService` 是纯骨架模板，供平台方继承填充真实硬件调用。
依赖方向：UI/模组 → XyzControllerHub → IMotionService → PlatformMotionAdapter/PlatformMotionService → 平台 DLL，反向仅通过 PositionUpdated 事件推送数据。
