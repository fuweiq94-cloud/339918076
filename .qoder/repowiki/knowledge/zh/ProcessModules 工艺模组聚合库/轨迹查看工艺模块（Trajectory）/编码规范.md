- 所有平台命令在 `Action(params object[] param)` 中通过 `param[0].ToString().ToUpper()` 做 switch 分发，未知命令返回 -1 并调用 `InsertAlarm` 上报。
- UI 控件统一设置 `DoubleBuffered = true`、`ResizeRedraw = true`、`SetStyle(ControlStyles.Selectable, true)` 以避免闪烁并支持键盘焦点。
- 跨线程 UI 更新统一通过 `InvokeRequired` 判断后 `BeginInvoke` 切回 UI 线程，避免直接跨线程访问控件。
- 配置类采用静态 `Load(name)` + 实例 `Save()` 模式，失败时返回默认空对象并写入 Debug 日志。
- 事件订阅全部使用命名方法 + `new EventHandler(...)` 显式委托构造，不使用 Lambda 表达式以兼容旧版工控机编译器。
- 业务初始化（创建 hub、订阅事件、动画启动）统一放在 `OnLoad` 而非构造函数，确保 VS 设计器不会触发副作用。
