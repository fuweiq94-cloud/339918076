- 所有事件订阅统一使用命名方法 + 显式 new EventHandler(...) 构造，避免 Lambda 表达式以兼容旧版 .NET 编译器。
- UI 与业务解耦：Form 不持有业务逻辑，仅通过 XyzControllerHub 暴露的属性/方法操作状态，并通过 Hub.Changed 事件反向同步 UI。
- 跨线程回调统一在 Hub_Changed 中通过 InvokeRequired + BeginInvoke 切回 UI 线程后再调用 SyncUiFromHub。
- 防重入保护：SyncUiFromHub 使用 _syncing 布尔锁防止 Hub 回调期间再次触发 UI 更新导致递归。
- 所有业务初始化（Hub 获取、事件绑定、初始刷新、动画启动）集中在 OnLoad 中完成，构造函数仅调用 InitializeComponent。
- JOG 服务按轴数组创建 AxisJogService[]，通过 ForEachJog 或 foreach 统一对三轴执行 SetMode/SetStepDistance/EmergencyStop 等操作。
